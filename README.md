# יומן גלים · Waves: Mood Diary

יומן מצב רוח פשוט לאנשים עם הפרעה דו-קוטבית, לאייפון ולאנדרואיד.
חינם, בלי פרסומות, בלי חשבון ובלי שרת. כל המידע נשאר מוצפן במכשיר.

A simple mood diary for people living with bipolar disorder, for iPhone and Android.
Free, no ads, no account, no server. All data stays encrypted on the device.

- מצב רוח, שינה, תרופות, אנרגיה ותגיות / Mood, sleep, medication, energy, tags
- מגמות וסיכום PDF לרופא / Trends and a PDF summary for your doctor
- "התוכנית שלי": סימנים מוקדמים, מה עוזר, אנשי אמון / "My plan": early signs, what helps, trusted people

האפליקציה היא יומן אישי ואינה מכשיר רפואי, אבחנה או טיפול.
This app is a personal diary, not a medical device, diagnosis or treatment.

Site: https://binrozenblum.co.il/galim/ · Privacy: https://binrozenblum.co.il/galim/privacy/

## Build

Capacitor 8 + Vite + TypeScript. See [app/NATIVE.md](app/NATIVE.md).

```
cd app && npm install && npm test && npm run build
```
